# Кому передавать отзыв

## Таблица: ситуация и отдел

Выбор отдела в поле «Кому передать». Если в отзыве несколько ситуаций, отделы перечисляются через точку с запятой.

| Ситуация | Отдел |
|---|---|
| Сорваны сроки, курьер нарушил правила | служба доставки |
| Повреждение в пути | склад; служба доставки |
| Производственный брак | контроль качества |
| Цвет, размер, описание не совпадают с карточкой | маркетинг (карточки товаров) |
| Не отвечают, ответили шаблоном | руководитель поддержки |
| Не вернули деньги, отказали в возврате | поддержка; бухгалтерия |
| Жалоба на цену, идеи упаковки | маркетинг |
| Ошибка сайта, оплаты, промокода; идеи по сайту | разработка сайта (и поддержка при ошибке оплаты) |
| Пожелания по ассортименту | закупки |
| Угроза жалобы в надзор или суд (Роспотребнадзор, суд, юрист) | руководитель поддержки |
| Спам, накрутка, оскорбления | модератор |
| Благодарность курьеру или сотруднику | служба доставки или поддержка, для сведения |
| Благодарность за товар, вопрос с ответом из базы | никому |

## Угроза жалобы в надзор или суд: юридического отдела нет

- Юридического отдела в магазине нет. Не указывать юротдел, юриста магазина или юридическую службу ни в поле «Кому передать», ни в черновике.
- Угроза жалобы в Роспотребнадзор, суд или обращения к юристу: передать руководителю поддержки. Срочность высокая (документ 07).
- Руководитель поддержки добавляется к отделу по сути жалобы. Пример: сорван срок доставки и угроза Роспотребнадзором → служба доставки; руководитель поддержки.
- Если клиент при этом требует деньги или компенсацию, в черновике ставить метку [решение менеджера] (документ 12).
