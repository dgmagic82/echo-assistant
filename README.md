# Эхо: ассистент поддержки по отзывам

Выпускной проект курса «Промпт-инжиниринг 3.0» (Zerocoder). «Эхо» помогает поддержке интернет-магазина товаров
для дома «Лавка Тепла»: размечает отзыв клиента (тональность, тип, темы, срочность, отдел), пишет черновик ответа
и показывает, из каких документов базы знаний взяты факты. Черновик проверяет и публикует человек.

Магазин учебный: правила, цены и адреса в базе знаний вымышленные.

## Как работает

```
отзыв или вопрос
   → поиск по базе знаний (FAISS, text-embedding-3-small): 4 фрагмента по смыслу + 2 шаблона ответа
   → в запрос всегда целиком: порядок при браке (04), классификация (07), маршрутизация (08), особые случаи (09)
   → Claude Haiku 4.5 через OpenRouter, ответ строго по схеме; промпт и 4 документа кэшируются на час
   → разметка, черновик, заметка для команды, ссылки на источники
```

- `kb/`: 16 документов базы знаний в Markdown, каждый раздел `##` становится фрагментом поиска.
- `prompts/system.md`: системный промпт (роль, правила, fallback, ограничения, формат).
- `echo/`: код (`kb.py` поиск, `chain.py` ответ по схеме, `config.py` настройки).
- `views/`: интерфейс Streamlit (разбор отзыва и просмотр документов базы).
- `eval/`: 15 тестовых входов с ожидаемыми ответами, скрипт прогона и отчёт.
- `index/`: готовый индекс FAISS, собирается `ingest.py`.

## Запуск локально

```powershell
uv sync
uv run streamlit run app.py
```

Ключ OpenRouter берётся из переменной `OPENROUTER_API_KEY`, из `.streamlit/secrets.toml` или из
`~/.secrets/common.env`. В репозитории ключа нет.

```powershell
uv run pytest                    # офлайн-тесты, без API
uv run python ingest.py          # пересобрать индекс после правки kb/
uv run python eval/run_eval.py   # прогон 15 тестовых входов (платно, около $0,06)
```
